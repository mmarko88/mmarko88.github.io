## 🧠 Building an agentic development framework

My main focus right now is building an **agentic development framework** on top of
[Devin](https://devin.ai) — the one powering real work on a 4,000-file Spring Boot codebase.
It's a measurement-first setup: context budgets, specialist checkpoints, read-only subagents,
and an eval harness that treats prompt changes like code changes.

- Writing the 11-part [Agentic Development series](/post/agentic/intro/) on patterns that
  actually paid off
- Running the eval harness against every PR touching skills or rules — three real regressions
  caught before rollout
- Experimenting with cheaper-model subagents for exploration tasks (5× cost reduction, no
  accuracy loss on measured research questions)
- Thinking about the next cliff: what's the shape of a 50×-cheaper tool-restricted agent?
