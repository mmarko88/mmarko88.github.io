# Skills

Pick by goal, not by name. The pipeline flows left to right; `learn` and `post-pulse`
close the loop by feeding outcomes back into the standards and `learnings/`.

| Goal | Skill |
|---|---|
| Decide what to work on next | `what-next` → ranked routes |
| Shape a topic into a brief (questionnaire) | `post-shape` → post brief |
| Research a topic before writing | `research` → `RESEARCH-*.md` |
| Scaffold, park, publish, or delete a post | `post-lifecycle` (new / idea / publish / delete / restore) |
| Draft a post | `write-post` |
| Verify a post (add `mode:deep` for persona reviewers) | `check-standards` |
| Cover image + share.png | `cover-image` |
| Interactive quiz checkpoints | `quiz` |
| Promotion drafts + launch checklist | `promote-post` |
| LinkedIn carousel PNGs | `linkedin-carousel` |
| Schedule the LinkedIn carousel | `linkedin-post` |
| Post an X thread | `post-to-x` |
| What worked? GA4 stats vs. standards | `post-pulse` |
| Record a durable lesson | `learn` → `learnings/` |

Loop: `what-next` → `post-shape` (→ `research` for fact gaps) →
`post-lifecycle new` → `write-post` →
`check-standards` → `cover-image`/`quiz` → `post-lifecycle publish` →
`promote-post` → `post-pulse` → `learn`.
